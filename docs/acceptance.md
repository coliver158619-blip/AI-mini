# H5 人工验收

启动前后端后，以手机或浏览器的 390 × 844 移动视口打开页面。演示数据会明确标注；播放统计按实际试听时长累计，不把点击播放直接当作听完整首歌。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 首页入口 | 打开首页，点击人物，再快速点两次 | 参考图的暖色房间与角色显示完整；人物有轻微晃动反馈；气泡能主动问候或回应；没有横向溢出。系统开启“减少动态效果”时，仍能得到文字反馈。 |
| 场景音推 | 点击放松、开心、专注、入睡、难过等场景，再发送一句自定义心情 | 对话记录显示所选场景或输入内容，回复与歌曲卡片来自后端；加载时避免重复提交。刷新后，历史对话仍能恢复。上游异常时显示原因、保留输入，不生成假回复；恢复连接后可以重试。 |
| 试听与收藏 | 点击有试听音源的歌曲，听一会儿后暂停，再切换另一首；收藏其中一首 | 音频确实播放，播放器状态一致；试听小样有明确说明；无音源的歌曲有反馈；收藏刷新后仍存在。 |
| 人物与能量 | 修改角色名字，保存后刷新；点击喂食两次 | 名字保持已保存值；喂食结果和能量来自接口，同一天重复喂食不会反复获得能量。 |
| 定位与天气 | 在安全上下文中允许定位，查看天气与相关推荐；再拒绝定位或关闭定位权限 | 成功时显示天气来源/城市和更新时间；失败时提供清楚说明与手动选择城市路径，不显示虚构天气。天气服务断网时可重试；旧数据有缓存提示。 |
| 日记翻页 | 进入日记，点击纸页中央上下区域掀页、纵向滑动、使用方向键、选择日期 | 每页对应明确日期，翻页有自然书页效果；首尾有明确提示，编辑与选中文字不会误翻页；日历能关闭；使用键盘时焦点可见。 |
| 日记保存 | 当天填写文字、上传照片或语音、选择位置与歌曲，提交生成，再刷新；打开历史日期 | 素材及生成正文持久保存，生成失败保留素材和原文；历史只读；打开页面不重复调用模型。 |
| 日记播报 | 点击读日记，再停止；播报时翻页 | 支持的浏览器能够播报中文并停止，翻页时不会继续读上一页。不支持或语音失败时有反馈，不影响阅读和编辑。 |
| 周/月/年报告 | 分别打开周报、月报、年报，前后切换周期；点击周热力日期、年度来信、月份最爱和歌曲榜单 | 周报显示 7 天分布，月报显示活跃指数和近 6 月趋势、四宫格高光，年报显示近 5 年趋势、来信和每月最爱；数据来自相应周期接口；歌曲可以试听；当前周期不能继续切到未来。 |
| 报告统计与持久化 | 记下当前统计；听完一个或多个试听片段并暂停，再重新进入日记和报告；刷新或重启 Flask 后复查 | 实际试听累计后时长有合理增长（分钟显示有取整），连续同一次播放不会因分段同步重复计次；数据库重启后记录还在。周/月/年使用相同底层播放记录。 |
| 折线表情 | 打开月报或年报，对比高低节点，点击或用 Tab + Enter 选择节点 | 节点从平静到开怀大笑，越高颜色越鲜艳；相同时长对应相同表情与颜色；选中后显示接口中的月份/年份和分钟数。仍以听歌时长为统计指标。 |
| 分享与辅助操作 | 分享报告，取消一次后重试；用键盘左右切换报告 tab；打开说明后按 Tab 和 Escape | 支持时调用系统分享，否则复制文案或展示可手动复制文本；取消分享不报成功。报告 tab 可键盘切换；弹窗焦点不跑到背景，关闭后回到触发按钮。 |
| 火花分享入口 | 点击首页“听歌续火花”，查看卡片与分享入口；分别短拉、下拉、横滑及滚动内容 | 展示当前装扮和后端 profile 中的连续听歌/陪伴天数；仅保留分享入口样式，不调用系统分享、不复制文案、不显示复制文本框。内容顶部下拉足够距离关闭，短拉回弹；横滑与内容滚动不误关闭，关闭后焦点回到火花入口。首页头像圆框与右下耳机角标位置协调。 |
| 聊天下拉关闭 | 下拉聊天标题、短拉回弹、横滑、滚动消息至顶部再下拉；输入草稿、打开历史对话并模拟键盘 | 标题和消息顶部可下拉关闭；正常滚动、输入及历史列表不误关闭，重新打开保留草稿，关闭后焦点回到入口。键盘出现时同样有效。 |
| 首页蒙版范围 | 手机安全区和横屏侧边安全区下观察首页顶部、房间与底部入口交界 | 蒙版与整页背景共享尺寸和定位，安全区边缘及内容交界无色差接缝，保留原有暖色渐变。 |
| 更多玩法一屏展示 | 使用 320×568、393×852、440×956 竖屏和短横屏；再打开播放器进入更多玩法 | 8 个入口及分组标题全部可见，卡片触摸高度至少 44px；页面无横向溢出或上下滚动，卡片避开安全区与播放器，入口可正常跳转。 |
| 二级页面背景与安全区 | 打开更多玩法、音乐人格、形象、报告、选歌、日记及天气；长页面滚到底，再检查播放器和天气昼夜横屏 | 页面背景连续覆盖上下及侧边安全区，不露出外层浅色条、不重复渐变；播放器下方背景连续，内容和按钮仍避开灵动岛及手势区。 |
| 音乐人格与新角色 | 更多玩法 → 音乐人格，筛选四个分组，选择角色并确认后返回首页、刷新；再进入形象衣橱 | 默认 INFP，16 张角色素材可浏览。未确认不改变首页，确认后首页、头像、火花卡片同步，衣橱选择独立保留，重启后保留。音乐偏好为角色设定，不展示推断分数。 |
| 充电榜 | 更多玩法 → 打榜，切换两类榜单、搜索明星、加载更多及搜索榜外明星 | 明星榜最多 1000，个人榜最多 100；搜索不改变名次；榜外提示清楚，当前用户充电值在两榜一致；明确标识示例，数据不影响真实能量。 |
| 角色页底部遮挡 | 人格/衣橱列表滚动到中间及末尾，检查手机手势区、横屏侧边安全区与播放器 | 确认区背景覆盖到底边和左右边缘，底层列表不透出、不误点；播放器仍可操作，最后一行能滚到确认区上方完整显示。 |
| 全屏 H5 与安全区 | 手机竖屏打开首页，检查灵动岛/刘海及底部手势区，再打开播放器、聊天键盘并横屏 | 页面铺满可用视口；导航避开顶部安全区，底部入口上移至少 24px 且不被播放器遮挡。常见竖屏一屏完整展示，极短横屏可滚动；不发生横向溢出。 |
| 空记录与网络失败 | 切换到没有听歌记录的历史周期；在开发者工具中断网再切换报告，恢复后重试 | 空周期显示引导而非假数据；请求失败有明确重试按钮；恢复网络后能加载，页面没有卡死。 |
| 两套形象与人物换装 | 衣橱先选KUGUY或KUGIRL，试穿并确认；再切回原音乐人格 | 14 / 17 套对应装扮可见；试穿不保存，确认返回首页；两个类别及每个人物上次装扮独立保留，首页、火花头像和公网文件名一致。 |

持久化检查应保持同一数据库路径，并正常停止、重启后端。清除或替换数据库属于重置数据，不用于验证“重启仍保留”。
